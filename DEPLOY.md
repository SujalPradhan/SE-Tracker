# Deploying SE-Tracker on Google Cloud (e2-micro, Mumbai)

One small VM runs everything: **gunicorn** (the Flask app) behind **Caddy**
(automatic HTTPS), with the SQLite database on the VM's disk and a nightly
backup to Cloud Storage. No code changes or managed database needed.

| | |
|---|---|
| Machine | `e2-micro` (2 shared vCPU, 1 GB RAM + 1 GB swap) |
| Region | `asia-south1` (Mumbai), ~30 ms from India |
| Disk | 10 GB `pd-balanced` |
| Cost | roughly $10–12/month (VM + disk + external IPv4). Check the [pricing calculator](https://cloud.google.com/products/calculator); the always-free e2-micro only applies in US regions. |

Commands below use the `gcloud` CLI ([install](https://cloud.google.com/sdk/docs/install)).
Replace `PROJECT_ID`, and pick a globally unique bucket name.

## 1. Project, VM, static IP, firewall

```sh
gcloud config set project PROJECT_ID
gcloud services enable compute.googleapis.com storage.googleapis.com

gcloud compute addresses create se-tracker-ip --region=asia-south1
gcloud compute addresses describe se-tracker-ip --region=asia-south1 --format='value(address)'
#   → e.g. 34.100.12.34

gcloud compute instances create se-tracker \
  --zone=asia-south1-a --machine-type=e2-micro \
  --image-family=debian-12 --image-project=debian-cloud \
  --boot-disk-size=10GB --boot-disk-type=pd-balanced \
  --address=se-tracker-ip --tags=http-server,https-server \
  --scopes=default,storage-rw

gcloud compute firewall-rules create allow-web \
  --allow=tcp:80,tcp:443 --target-tags=http-server,https-server
```

**Hostname.** If you own a domain, add an `A` record pointing to the static IP.
Otherwise use the free wildcard DNS `34-100-12-34.sslip.io` (your IP with
dashes). Either way, Caddy fetches the HTTPS certificate on its own.

## 2. Backup bucket (30-day retention)

```sh
gcloud storage buckets create gs://BUCKET_NAME --location=asia-south1
echo '{"rule":[{"action":{"type":"Delete"},"condition":{"age":30}}]}' > lifecycle.json
gcloud storage buckets update gs://BUCKET_NAME --lifecycle-file=lifecycle.json
```

## 3. Google Sign-In for /admin

1. Console → **Google Auth Platform** → *Branding*: app name "SE-Tracker",
   support email. *Audience*: **External**, then **Publish app** (so it isn't
   limited to listed test users). Only basic scopes (`openid email profile`)
   are used, so no Google verification review is needed.
2. *Clients* → **Create client** → *Web application*.
   - Authorized redirect URI: `https://<your-host>/admin/callback`
3. Copy the client ID and secret into `/etc/se-tracker.env` (next step).

Only emails on the allowlist in `admin.py` (or the `ADMIN_EMAILS` env var)
get in. Everyone else sees "Not authorised".

## 4. Install on the VM

```sh
gcloud compute ssh se-tracker --zone=asia-south1-a
curl -fsSLO https://raw.githubusercontent.com/SujalPradhan/SE-Tracker/main/deploy/gcp/setup.sh
sudo bash setup.sh https://github.com/SujalPradhan/SE-Tracker.git
sudo nano /etc/se-tracker.env      # SITE_ADDRESS, GOOGLE_CLIENT_ID/SECRET, BACKUP_BUCKET
sudo systemctl restart se-tracker caddy
```

Check:

```sh
systemctl status se-tracker caddy --no-pager
curl -I https://<your-host>/login               # 200
sudo /usr/local/bin/se-tracker-backup            # "backup ok"
```

The database starts empty (SEP2026). TAs register at `/register`, the seeded
read-only demo is at `/demo`, and the admin overview is at `/admin`.

## Redeploying

```sh
gcloud compute ssh se-tracker --zone=asia-south1-a -- \
  'cd /srv/se-tracker && sudo -u setracker git pull && sudo -u setracker .venv/bin/pip install -q -r requirements.txt && sudo systemctl restart se-tracker'
```

## Restoring a backup

```sh
gcloud storage ls gs://BUCKET_NAME/se-tracker/
sudo systemctl stop se-tracker
gcloud storage cp gs://BUCKET_NAME/se-tracker/se_tracker-YYYYMMDD-HHMMSS.db.gz /tmp/
gunzip -c /tmp/se_tracker-*.db.gz | sudo -u setracker tee /var/lib/se-tracker/se_tracker.db >/dev/null
sudo systemctl start se-tracker
```

## Environment variables

| Var | Purpose |
|---|---|
| `SECRET_KEY` | Session signing key (generated by `setup.sh`). |
| `DATABASE_URL` | `sqlite:////var/lib/se-tracker/se_tracker.db` |
| `HTTPS_ONLY=1` | Secure session cookies. |
| `BEHIND_PROXY=1` | Trust Caddy's `X-Forwarded-*` headers (needed for the OAuth redirect URL). |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Admin Google Sign-In. |
| `ADMIN_EMAILS` | Optional comma-separated override of the admin allowlist. |
| `SITE_ADDRESS` | Hostname Caddy serves. |
| `BACKUP_BUCKET` | Bucket for nightly backups. |
